# Як викласти програму в інтернет

Після цього посилання працюватиме цілодобово, навіть коли твій комп'ютер
вимкнений. Це безкоштовно. Загалом — хвилин 15.

Все, що можна було зробити без тебе, вже зроблено: код готовий, репозиторій
створено, перший коміт зроблено. Лишились кроки, де потрібен твій акаунт.

---

## Крок 1. Створити репозиторій на GitHub

1. Відкрий **https://github.com/new**
2. **Repository name:** `reitynh-vstupnyka` (або будь-яка інша назва)
3. Постав **Public** (для безкоштовного тарифу Render так простіше)
4. **Нічого не додавай** — ні README, ні .gitignore, ні ліцензію.
   Вони вже є, інакше буде конфлікт
5. Натисни **Create repository**

## Крок 2. Завантажити код на GitHub

GitHub покаже готові команди. Виконай оці дві в папці програми,
підставивши свій нікнейм замість `ТВІЙ-НІКНЕЙМ`:

```bash
git remote add origin https://github.com/ТВІЙ-НІКНЕЙМ/reitynh-vstupnyka.git
```

```bash
git branch -M main && git push -u origin main
```

При першому завантаженні відкриється вікно входу в GitHub — увійди у ньому.

## Крок 3. Підключити Render

1. Відкрий **https://render.com** і зареєструйся через GitHub
   (кнопка **Sign in with GitHub** — окремий пароль не потрібен)
2. Натисни **New +** → **Web Service**
3. Обери свій репозиторій `reitynh-vstupnyka` зі списку
4. Render сам прочитає файл `render.yaml` і підставить налаштування.
   Перевір, що стоїть:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** Free
5. Натисни **Create Web Service**

Перше складання триває 2–4 хвилини. Коли зверху з'явиться зелений напис
**Live** — готово. Посилання буде у вигляді:

```
https://reitynh-vstupnyka.onrender.com
```

Його можна давати будь-кому.

## Що варто знати про безкоштовний тариф

**Сервіс засинає.** Після 15 хвилин без відвідувачів Render присипляє
програму. Наступне відкриття триватиме ~30–50 секунд, поки вона
прокидається. Далі все швидко. Це нормальна поведінка безкоштовного тарифу.

**Кеш очищається** при кожному пробудженні — програма просто завантажить
дані заново.

**Збережені спеціальності й бали не спільні.** Вони зберігаються в браузері
кожного відвідувача окремо, тому ніхто не побачить твоїх даних, а ти — їхніх.

---

## Як оновлювати програму

Після будь-яких змін у коді:

```bash
git add -A && git commit -m "опис змін" && git push
```

Render помітить зміни і перезбере сервіс сам, за пару хвилин.

---

## Якщо Render не підійде

Той самий репозиторій без переробок приймуть:

- **Railway** (railway.app) — не засинає, але безкоштовні години обмежені
- **Fly.io** (fly.io) — щедріший тариф, але налаштування складніше
- **Koyeb** (koyeb.com) — теж має безкоштовний тариф без засинання

Скрізь схема однакова: увійти через GitHub → обрати репозиторій → запустити.
